# Search, screening and evidence

Start the bounded pilot from the proposed core question and its subquestions, not the broad topic label alone. Translate each subquestion into concept groups, synonyms and source-specific queries; keep each query tied to the question component it tests. Record pilot queries, sources, date, result volume, existing-review coverage and synthesis-gap assessment in `02_search/pilot-search.md`. Compare relevant prior reviews and state the proposed contribution in `02_search/prior-reviews.json`; refine an overbroad or under-supported question before locking it. Start full discovery from the locked question and record its filters, page limits, result counts, errors and last successful page. In `coverage.json`, give every search topic one or more `question_ids`; the topic mappings must cover every subquestion. Select complementary sources appropriate to the field. For CS include arXiv and, when relevant and available, conference or journal sources and web search. Treat web-ranked results as candidate discovery, not exhaustive database retrieval. Follow citation links backwards and forwards and record stopping reasons. Search results, screened reports, accessible full texts and cited studies are distinct sets.

The only bundled direct API adapters are arXiv and Crossref. Run them with `python scripts/search.py arxiv QUERY --output FILE` or `python scripts/search.py crossref QUERY --output FILE`. They require network access. For a paginated arXiv query use `--limit` and `--page-size`; for Crossref also use `--mailto` if available. Each writes a JSON envelope with source, query, retrieval time, records, pagination, status and errors, including on network failure. Inspect the envelope and process exit code; do not assert inaccessible sources succeeded. No other database API adapter or hosted search service is bundled. If the runtime exposes hosted web search, it may be used as a separate candidate-discovery path, not as exhaustive database retrieval; log its actual query, date, result count and limitations. Tool availability and policies govern this fallback.

Use `python scripts/deduplicate.py SOURCE1.json SOURCE2.json --output GROUPS.json` to group matching DOI or arXiv IDs. Preserve the original records and assign stable citation IDs separately: group fingerprints are not stable citation keys. Same-title fuzzy candidates require review; preprints, published papers and follow-up reports get explicit relationships, not blind merging. Preserve source IDs and versions. Filter titles and abstracts to include/exclude/uncertain and document reasons. Citation count can order reading, not determine eligibility or quality.

For each source record access level (full text, abstract, metadata), accessible URL and bibliographic verification. Each important claim requires a source ID, evidence text or concise observation, locator (page/section/figure as actually known), population/design, limitation and support/contradiction status. Never invent page numbers or infer unseen methods. Compare contradictory studies and design differences. After coverage screening, create a question-specific study appraisal and a cross-study synthesis matrix before finalizing the outline; follow `references/evidence-synthesis.md`. Appraise important primary studies on dimensions that matter to the question, with source locators and qualitative rationale, not a universal numeric score. Use an available authorized full-text workflow only if its own preconditions are satisfied; otherwise mark missing and limit conclusions. Plan enough relevant, verified literature to support a final bibliography of at least 40 unique cited works, including at least 60% from the latest five publication years. This is a final manuscript requirement, not a minimum for raw search results or included candidates; expand relevant searching rather than padding citations. If core evidence or the final bibliography requirement remains unattainable after bounded searches, block the affected section or deliver a clearly labeled limited result instead of inventing sources.
