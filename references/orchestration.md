# Orchestration and handoffs

Initialize an isolated schema-v3 run with scripts/init_run.py. Before discovery, save 01_plan/scope.md and a proposed 01_plan/core-question.json. Advance to searching only after the primary agent judges the question focused and answerable. Use that phase for a bounded scoping search; assess literature volume, compare prior reviews, state the specific contribution, and evaluate the synthesis gap. Refine if needed, record 02_search/pilot-search.md and 02_search/prior-reviews.json, then lock the question before full discovery. Run the full search from locked subquestions. After coverage passes, build the question-specific appraisal and synthesis matrix in references/evidence-synthesis.md and have the primary agent accept them before finalizing 01_plan/outline.md and 01_plan/sections.json.

Derive the outline from the core question and accepted synthesis units, not from a list of search-result titles. Split the question into answerable subquestions; each body section in sections.json must name the question IDs and synthesis IDs it addresses, and every subquestion and synthesis unit must map to at least one section. Rank eligible sections by importance (priority 1 highest); dependencies take precedence. State writing order and final reading order separately. For each chapter, record dispatch with gate.py before actually assigning the task, then wait for its returned artifact, record submission and inspect the prose, source locators and delegate output. Accept or return that chapter for delegated revision before dispatching the next. Acceptance findings must trace integrated claims across the assigned sources and account for conditions and counterevidence. Pass accepted content, terminology, evidence locators, contradictions and open questions forward. Never rewrite delegated manuscript prose as the primary agent.

If evidence changes, update the appraisal, synthesis matrix and their primary-agent review before reassessing from the earliest affected chapter. Update the outline and sections manifest when synthesis mappings change. Stop any active delegate, record cancellation, and reassess in order. If an accepted chapter is wrong, invalidate it and all dependent later chapters, then delegate repairs in order. A tool state transition does not itself interrupt a running delegate.

After every body chapter passes, plan figures and tables using references/figures.md. Record figure inputs tied to the accepted body snapshot. Delegate image creation, then have the primary agent inspect every final PNG against evidence and the plan. If a figure fails content or quality review, preserve the finding and delegate a replacement; do not self-correct the generated artifact. Re-review the replacement and the full figure set before advancing. Delegate the review approach, abstract, introduction and conclusion; check the approach against actual search logs and check conclusion directions against the accepted gap matrix.

Delegate cross-section review, defensive-writing review and any corrections. Create the working title with the initial question; run final title naming on the complete, stable manuscript using the locked question and boundaries, and delegate a fresh title if accepted content changes. Generate citation-resolved Markdown and PDF only after manuscript assembly. A successful gate or QA script does not prove a real agent handoff or scientific correctness: reconcile event records with actual work and inspect original sources and rendered PDF pages.

If a required capability is unavailable, record the limitation, use only allowed fallbacks and deliver a clearly limited result. Do not silently replace subagents with the primary agent, fabricate source coverage, or claim PDF visual verification without inspecting the generated pages or contact sheet.
