# 织论 · Review Loom

Coordinate a publication-oriented narrative review. Resolve all scripts relative to this SKILL.md, not the user's working directory. The primary agent owns scope, outline, importance ranking, sequential dispatch, acceptance, run state and integration. Delegate manuscript prose, revisions, figure generation and regeneration, abstract, introduction, conclusion, title and reviewer edits. The run starts from the user's request and should proceed without routine human intervention. Record assumptions. If evidence or a capability is unavailable, use an allowed fallback or produce an explicitly limited result; never fabricate completion.

## Workflow

1. Read references/core-question.md, references/orchestration.md, references/search-evidence.md, references/evidence-synthesis.md, references/quality-gates.md and references/defensive-writing.md. Initialize an isolated run and write 01_plan/scope.md plus a proposed 01_plan/core-question.json before discovery. Use scripts/gate.py for every phase transition. Check available search, full-text, delegation, image-generation, Pandoc, Chromium and Python capabilities.
2. In the searching phase, run a bounded scoping search to test the proposed question's literature volume, existing-review coverage and synthesis gap. Compare prior reviews and record the specific contribution in 02_search/prior-reviews.json before locking the question. Refine the scope autonomously when needed. Build full search queries from the locked subquestions. For CS include arXiv, relevant conferences and journals, and hosted web search when available. Record actual queries, search status, candidate queue, citation tracing and access level. Build a sufficiently broad evidence pool to support at least 40 distinct works actually cited in the final manuscript, with at least 60% from the latest five publication years. Do not pad with irrelevant citations. If the focused question lacks enough evidence or the counts remain insufficient after bounded work, deliver a clearly marked limited result.
3. After the evidence gate passes, complete the question-specific study appraisal and cross-study synthesis matrix in references/evidence-synthesis.md. The primary agent accepts these artifacts against the sources before the outline gate can pass. Finalize an outline mapping every subquestion and synthesis unit to one or more chapters. Rank eligible chapters by importance (priority 1 is highest), with dependencies taking precedence. Delegate one chapter at a time. The primary agent must inspect each submission and accept it before dispatching the next chapter. Pass forward accepted text, terminology, evidence locators, synthesis units and unresolved questions. An unacceptable chapter is returned to a subagent for revision; the primary agent does not rewrite it.
4. After all body chapters are accepted, plan at least five figures and four tables for the main manuscript. Use five to eight figures and four to six tables as a default range, subject to venue limits and explanatory value. Delegate direct generation of final figure images; insert the accepted image into the manuscript without recreating it as Draw.io. Follow references/figures.md and references/figure-style.md. The figure subagent checks print-size quality before submission. The primary agent independently checks every image against the accepted plan and paper evidence; reject a content mismatch and delegate regeneration.
5. After the body and figures are stable, delegate the review-approach disclosure, abstract, introduction and conclusion. The primary agent checks the method disclosure against actual search logs and maps each conclusion research direction to the accepted evidence-gap matrix. Delegate cross-section review, counterevidence/omission review, defensive-writing review and any needed edits. After the complete manuscript and figures are stable, delegate final title naming against the locked core question, scope and full manuscript. Keep citation keys in source chapters and number citations only after final assembly so a source cited in several chapters receives one unified reference number.
6. Validate the final Markdown and bibliography, then create the citation-resolved readable Markdown and PDF by following references/citations-output.md and references/pdf-output.md. The default deliverables are Markdown and a QA-checked PDF; do not create DOCX unless the user explicitly requests it. Keep the PDF build intermediates, rendered page images, contact sheet and machine-readable validation report with the run. Final acceptance requires the PDF and its validation report.

Use scripts/gate.py as the only writer of schema-v3 run-state transitions. A gate checks declarations and file hashes, not scientific truth or whether a delegate actually performed its task. Inspect original sources, real delegate submissions and rendered outputs. A review draft is not proof of publication or peer review.
